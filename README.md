# Dinesh Karnati engineering portfolio

Static portfolio for https://denishkarnati.github.io/.

Publish from main, root folder in Settings / Pages. No build step required. Includes six project articles, real hardware references, interactive explanations, resume downloads, and the approved Lucid software block diagram.

## Design and maintenance

The centered editorial layout uses a floating navigation bar, a monochrome profile photograph, compact highlights, and large project showcases. General composition was inspired by Jonny Czar's Portfolio 2024 presentation on Behance; no reference artwork or personal content is reused.

Edit editorial.css for the current visual theme and portfolio.js for navigation, project filtering, and reduced-motion-aware reveals. The eight HTML pages are static and deploy directly from main.
