01 / MY CONTRIBUTION

Problem

Powertrain ECU software depends on low-level drivers, middleware, and application integration working together on the target. At Lucid, I developed and debugged platform software at that hardware–software boundary.

Constraint

The work ran within automotive development and validation processes. A module working in isolation does not establish correct behavior after its hardware interfaces, platform dependencies, and application interactions are integrated.

Decision

I developed low-level drivers and middleware and worked across AUTOSAR BSW, RTE, and MCAL integration. I used on-chip debugging to investigate hardware/software integration issues and reviewed real-time code for responsiveness.

Result

I contributed integrated ECU platform software and repeatable bench-validation workflows. I wrote Python and Shell automation for validation and supported code review, defect triage, and software integration. My full-time role ran January 2024–April 2026, following an August–December 2023 internship.
